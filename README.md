# HQGroundControl

> 基于 QGroundControl (QGC) 二次开发的第三方无人机地面站。

## 📖 项目介绍

HQGroundControl 是基于开源无人机地面站 QGroundControl 进行二次开发的第三方版本。

本项目在保留 QGroundControl 原有主要功能的基础上，根据实际无人机使用、调试及教学需求进行了功能扩展和优化，并加入了部分原版 QGroundControl 中未提供的自定义功能。

## ✨ 主要功能

* 保留 QGroundControl 原有主要功能
* 支持 PX4和ardupilot固件的飞控
* 支持无人机参数配置与调试
* 支持传感器校准
* 增加主界面快速数据和HUD
* 针对实际使用场景进行功能及界面优化

> 后续版本将持续完善和增加相关功能。
